# CrashLab

Follow [skills/crashlab/SKILL.md](skills/crashlab/SKILL.md) for the canonical
Hermes workflow: inspect the user's application and intended behavior, prepare
an experiment, approve execution, reproduce a valid failure, repair only the
application and rerun the same experiment.

For installation and a supplied-case exercise before using your own app, see
[docs/FIRST_RUN.md](docs/FIRST_RUN.md). The bundled fixture is an example, not
evidence that Hermes produced a repair. Keep recorded results scoped to the
configured assertions and use the supported approval path.
